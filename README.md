# Python Automation Tools 🐍⚙️

Colección de pequeñas herramientas desarrolladas en Python para automatización, soporte técnico y tareas de mantenimiento.

El objetivo de este repositorio es reunir utilidades sencillas y prácticas que puedan facilitar tareas habituales en entornos de soporte y administración de computadores.

## 💻 Áreas de aplicación

- Automatización de tareas
- Soporte técnico
- Administración de archivos
- Copias de seguridad
- Diagnóstico básico de sistemas
- Organización de información

## 🚀 Herramientas incluidas

### 🖥️ System Report

Genera un reporte básico del computador con información del sistema operativo, procesador, arquitectura y almacenamiento.

### 💾 Backup ZIP

Permite crear una copia comprimida de una carpeta para facilitar respaldos de información.

### 📁 File Organizer

Organiza automáticamente los archivos de una carpeta según su extensión.

## 🛠️ Tecnologías

- Python
- Librerías estándar de Python
- Automatización
- Administración de archivos
- Diagnóstico básico de sistemas

## ▶️ Ejecución

Clona el repositorio:

```bash
git clone https://github.com/eletogu/python-automation-tools.git
```

Entra en la carpeta:

```bash
cd python-automation-tools
```

Ejecuta cualquiera de las herramientas:

```bash
python system_report.py
```

También puedes ejecutar:

```bash
python backup_zip.py
```

o:

```bash
python file_organizer.py
```
